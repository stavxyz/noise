Example Patterns

Click on any example to load it into the editor:

Dark Ambient

note("c3 eb3 g3 [bb3 c4]") .s("sawtooth") .lpf(sine.range(400, 2000).slow(8)) .room(0.5)

Simple Beat

s("bd sd, hh*8") .bank("RolandTR909")

Noise Generator

note("<[c2 c3]*4 [eb2 eb3]*4 [g2 g3]*4 [bb2 bb3]*4>") .s("square") .cutoff(500) .lpf(perlin.range(200, 2000))

Bass + Drums

stack( s("bd*2, ~ sd, [~ hh]*2").bank("RolandTR808"), note("c1 eb1 g1 bb1").s("sawtooth").lpf(400) )

Melodic Delay

n("0 2 [4 6] [3 5]") .scale("C:minor") .s("triangle") .lpf(sine.range(300, 3000).slow(4)) .delay(0.5) .delaytime(0.125)

Ambient Noise

note(perlin.range(30, 80).segment(16)) .s("sine") .lpf(perlin.range(200, 4000).slow(8)) .room(0.9) .size(0.9)

Tips

  • Use note() for MIDI note values or n() with .scale() for scale degrees
  • Use s() to select sounds (e.g., "sawtooth", "sine", "square", "triangle")
  • Use lpf() for low-pass filtering, hpf() for high-pass
  • Add effects like .room() for reverb, .delay() for delay
  • Use stack() to layer multiple patterns
  • Use pattern notation like * for repetition, [] for sub-divisions
